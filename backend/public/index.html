API Astronomía

Aquí encontrarás preguntas y respuestas sobre planetas, estrellas y otros cuerpos celestes. Ideal para utilizar en proyectos educativos.

Documentación de la API para el manejo de preguntas, cursos y usuarios:

(Esta API está en español, cuida las tildes por favor)

Preguntas (questions)

  • GET /api/questions Obtener lista completa de preguntas
  • GET /api/questions/{questionID} Obtener pregunta por ID
  • GET /api/questions?subject=estrellas&difficulty=easy Filtrar preguntas por tema y/o dificultad
  • GET /api/questions?question=planeta sistema Buscar preguntas por enunciado (coincidencia parcial, podés poner varias palabras que creas que puedan estar en el enunciado)
  • POST /api/questions Crear una pregunta (difficulty solo acepta los valores: easy, medium, hard)
  • PUT /api/questions/{questionID} Actualizar una pregunta (difficulty solo acepta los valores: easy, medium, hard)
  • DELETE /api/questions/{questionID} Eliminar una pregunta

Cursos (courses)

  • GET /api/courses Obtener lista completa de cursos
  • GET /api/courses/{courseID} Obtener curso por ID
  • GET /api/courses?subject=agujeros Filtrar cursos por tema
  • GET /api/courses?title=introducción estrellas Buscar cursos por título (coincidencia parcial, podés poner varias palabras que creas que puedan estar en el título)
  • POST /api/courses Crear un curso (level solo acepta los valores: 1, 2, 3, 4, 5)
  • PUT /api/courses/{courseID} Actualizar un curso (level solo acepta los valores: 1, 2, 3, 4, 5)
  • DELETE /api/courses/{courseID} Eliminar un curso

Usuarios (users)

  • GET /api/users Obtener lista completa de usuarios
  • GET /api/users/{userID} Obtener usuario por ID
  • POST /api/users Crear un usuario
  • PUT /api/users/{userID} Actualizar un usuario
  • DELETE /api/users/{userID} Eliminar un usuario
