API Astronomía

Aquí encontrarás preguntas y respuestas sobre planetas, estrellas y otros cuerpos celestes. Ideal para utilizar en proyectos educativos.

Preguntas

  • GET /api/questions Obtener lista completa de preguntas
  • GET /api/questions/{questionID} Obtener pregunta por ID
  • POST /api/questions Crear una pregunta
  • PUT /api/questions/{questionID} Actualizar una pregunta
  • DELETE /api/questions/{questionID} Eliminar una pregunta

Usuarios

  • GET /api/users Obtener lista completa de usuarios
  • GET /api/users/{userID} Obtener usuario por ID
  • POST /api/users Crear un usuario
  • PUT /api/users/{userID} Actualizar un usuario
  • DELETE /api/users/{userID} Eliminar un usuario
